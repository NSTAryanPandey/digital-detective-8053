# Mission 1 — Know your computer

## 1. Task / objective
Understand how the IPOS (Input, Processing, Output, Storage) cycle works, separate everyday hardware from software, and identify real-world computer-based systems.

## 2. Work completed
I traced a daily task through all four IPOS stages, categorized the hardware and software I actually use, and broke down three computer-based systems we see around us.

### Task 1.1 — IPOS trace
**Activity:** Searching for a Python error on Google
- **Input:** Typing the error message on the keyboard and hitting Enter.
- **Processing:** The browser sends the query, and the CPU/Google servers process and rank the matching results.
- **Output:** The list of solutions and links shows up on the screen.
- **Storage:** The search history and cached pages get saved locally on the SSD and synced to the cloud.

### Task 1.2 — Hardware and software
| Item | Hardware / Software | Type | Purpose |
|---|---|---|---|
| MacBook Pro | Hardware | System unit | Main machine for coding and college work |
| Mouse / Trackpad | Hardware | Input device | Navigating and clicking |
| Webcam | Hardware | Input device | Video calls and online classes |
| iPhone | Hardware | Mobile device | Communication and daily apps |
| macOS | Software | Operating system | Runs the laptop and manages hardware |
| Google Chrome | Software | Application | Browsing the web and accessing portals |
| VS Code | Software | Application | Writing and running code |
| Activity Monitor / Antivirus | Software | Utility | Monitors system health and security |

### Task 1.3 — Computer-based systems
| System | Main purpose | Input | Output |
|---|---|---|---|
| ATM | Withdrawing and managing cash | Debit card + PIN + amount | Cash dispensed + receipt/screen update |
| Traffic signal | Regulating road traffic | Pre-set timers or road sensors | Red, yellow, and green light changes |
| Smart TV | Streaming and media playback | Remote button press or voice command | Video on screen + audio through speakers |

## 4. My understanding
Everything a computer does—even a basic Google search—follows the same Input, Processing, Output, and Storage loop. Breaking it down made it much clearer how physical hardware and different layers of software (OS, apps, utilities) actually work together behind the scenes.
