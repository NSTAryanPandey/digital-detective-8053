## 4. What I Learned
Across these missions, I got much more comfortable working directly in the terminal instead of relying on a graphical interface for everything. I now have a better grasp of how an OS manages running processes and file permissions, how Python runs code line by line compared to compiled languages, and how computers store data using binary and hex. Practicing Git branches and pull requests also showed me how to isolate changes before merging them into `main`. On top of that, running the networking commands made it way clearer how domain names resolve to IP addresses and travel across routers.

## 5. Difficulties Faced
I ran into a few minor snags along the way. Pasting multiple lines into the Python interactive shell at once got me stuck on the `...` prompt, `traceroute` took a long time on unresponsive hops, and early on I wasn't sure if switching Git branches required a new terminal window.

## 6. How I Resolved Them
I used `Ctrl+C` to stop stuck commands like `traceroute` and exit the multiline Python prompt, then ran things one line at a time. For Git, I made a habit of running `git status` and `git branch` before committing so I always knew which branch I was working on.
